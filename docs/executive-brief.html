What it is

A private web platform that automatically finds GIS and telecom opportunities for JSAN — government tenders, RFPs, RFQs, and procurement notices for fibre & network projects, 5G rollout, OSS/BSS, and geospatial platforms — before the Business Development team has to go looking.

It collects these leads from publicly available sources only — official government procurement APIs, tender APIs, RSS feeds, and open-data portals — then organizes, de-duplicates, and searches them. Every opportunity is scored against JSAN's service lines, with GIS and telecom weighted highest, and ranked so that leads in JSAN's operating locations surface first — the team sees on-strategy, on-footprint work before manually scanning dozens of portals.

Delivery status

Working now

A complete, clickable Next.js + TypeScript application — all screens, a world-map footprint view, filters, charts, fit scoring, and 53 sample opportunities weighted toward GIS & telecom. Runs locally and deploys to the cloud with no extra infrastructure.

Verified in Docker · 23 Jul

The full enterprise stack — Python (FastAPI) + PostgreSQL + Redis + OpenSearch — runs with one command and passed 24/24 automated end-to-end tests plus 13 unit tests: login & role-based access, search, filters, pagination, live-data ingestion and data integrity. The backend was rebuilt in Python to match the company's engineering standard, and the UI now renders the live tenders.

Data & accuracy

Verified 23 Jul 2026 — live government data connected

The platform now ingests real UK government tenders automatically.

Live

With the full stack running, the portal pulls real tenders from the official UK Contracts Finder OCDS API (Cabinet Office, no key, Open Government Licence) on a built-in schedule — e.g. a Ministry of Defence £2.5M notice, Southend City Council, Heathrow Airport Ltd. Every record links to its official gov.uk notice, and every raw API response is captured with a SHA-256 fingerprint for full provenance.

Sample

The zero-infrastructure demo mode (UI only, no Docker) still uses the labeled 53-record sample set, and a few seeded demo rows remain for continuity — the sidebar marker shows "Live data connected" or "Sample dataset" so the team always knows which is which.

➡️ Quality audit: the platform passed an iterative rubric review — 34/35 (97%), up from a 51% baseline — including forensic anti-fabrication checks (sampled records verified against the live gov.uk notice pages), 13 unit tests and 24 end-to-end tests. Full detail in score.md. Next sources: TED Europa (free), SAM.gov (free key).
