Anticipated questions

Yes — official public APIs and open-data portals under open licences. Every raw response is hashed (SHA-256) for provenance.

JWT auth + roles (Admin, BD, Sales, Manager, Read-Only). Demo credentials to be rotated before any shared deployment.

ScopeHow many sources are connected?

Framework is pluggable. UK Contracts Finder is live; SAM.gov, TED and RSS are scaffolded. Adding a source is a small module.

Architecture is. Before launch: rotate credentials, provision prod infra, expand connected sources.
